1. Detención de Emergencia

Métodos: EDO (RK2 Heun, RK4), Integración (Trapecio, Simpson 1/3, Romberg) y Raíces (Bisección, Newton-Raphson, Secante).

Modelo: dx/dt = v, dv/dt = −a(v,t) tras tiempo de reacción tr.

2. Deterioro Mecánico

Métodos: Sistemas Lineales SPD (Jacobi, Gauss-Seidel, LU, Gradiente Conjugado) y Raíces (Bisección, Newton, Secante).

Modelo: Calibración (ΦTΦ + λI)θ = ΦTy y umbral D(t) − Dumbral = 0.

3. Oscilaciones por Viento

Métodos: EDO de 2.º orden (RK2, RK4) e Integración acumulada (Trapecio, Simpson 1/3, Romberg).

Modelo: m·x'' + c·x' + k·x = F(t) y energía ∫ x(t)2 dt.

4. Reconstrucción de Sensores

Métodos: Interpolación (Lagrange, Newton diferencias divididas, Splines cúbicos naturales) y Raíces de cruce.

Modelo: Reconstrucción de registros ocultos y evaluación de ruido / fenómeno de Runge.

Módulo 1 — Detención de Emergencia de Cabinas

Modelo Matemático: Para 0 ≤ t ≤ tr: dx/dt = v0, dv/dt = 0. Para t > tr: dx/dt = v, dv/dt = −(a0 + cd·v2).
Referencia Analítica (cd = 0): tdet = tr + v0/a0,   xdet = v0·tr + v02/(2a0).

Módulo 2 — Deterioro Mecánico y Mantenimiento

Calibración Lineal SPD: A·x = b (n = 4 parámetros de desgaste).
Ecuación de Umbral: f(t) = D0 + α·t + β·t2 − Dumbral = 0  ⇒  t* = [−α + √(α2 − 4β(D0 − Dumbral))] / (2β).

Esquema SQL Relacional Implementado (PostgreSQL / SQLite)

CREATE TABLE caso_estudio (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  nombre VARCHAR(100) NOT NULL,
  modelo_version VARCHAR(20) NOT NULL
);

CREATE TABLE escenario (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  caso_id INTEGER NOT NULL REFERENCES caso_estudio(id),
  tipo VARCHAR(30) CHECK (tipo IN ('NORMAL','ESTRES','MAL_CONDICIONADO')),
  parametros_json TEXT NOT NULL,
  fuente_datos VARCHAR(120) NOT NULL
);

CREATE TABLE simulacion (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  escenario_id INTEGER NOT NULL REFERENCES escenario(id),
  fecha TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  usuario_equipo VARCHAR(80),
  estado VARCHAR(30) DEFAULT 'COMPLETADO'
);

CREATE TABLE ejecucion_metodo (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  simulacion_id INTEGER NOT NULL REFERENCES simulacion(id),
  metodo VARCHAR(60) NOT NULL,
  tolerancia REAL,
  paso REAL,
  max_iter INTEGER,
  convergio BOOLEAN NOT NULL,
  tiempo_ms REAL NOT NULL
);

CREATE TABLE iteracion_resultado (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  ejecucion_id INTEGER NOT NULL REFERENCES ejecucion_metodo(id),
  numero INTEGER NOT NULL,
  aproximacion_json TEXT NOT NULL,
  residual REAL,
  error_abs REAL,
  error_rel REAL
);

CREATE TABLE resultado_resumen (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  ejecucion_id INTEGER NOT NULL REFERENCES ejecucion_metodo(id),
  referencia TEXT,
  valor_json TEXT NOT NULL,
  metrica_error_json TEXT NOT NULL,
  interpretacion TEXT
);
