Incluye la implementación funcional de los cuatro métodos de Sistemas Lineales (Jacobi, Gauss-Seidel, Factorización LU y Gradiente Conjugado) con Teoría de Errores Transversal en el Módulo 2 y la arquitectura de los cuatro módulos.

1. Detención de Emergencia

Cálculo de tiempo y distancia de frenado de cabinas tras tiempo muerto de reacción y desaceleración controlada.

Métodos: RK2, RK4, Trapecio, Simpson 1/3, Romberg, Bisección, Newton, Secante.

2. Deterioro Mecánico

Calibración SPD por mínimos cuadrados y estimación de tiempo hasta alcanzar el umbral crítico de desgaste.

Activo S1: Jacobi, Gauss-Seidel, LU, Gradiente Conjugado + Raíces.

3. Oscilaciones por Viento

Respuesta dinámica de una cabina suspendida bajo ráfagas de viento y energía acumulada de vibración.

Métodos: RK2, RK4, Trapecio, Simpson 1/3, Romberg.

4. Reconstrucción de Sensores

Recuperación de señales telemétricas con datos faltantes y evaluación de estabilidad frente a ruido y espaciamiento.

Métodos: Lagrange, Newton (Dif. Divididas), Splines Cúbicos.

Módulo 1: Detención de Emergencia de Cabinas

Modelo EDO: dx/dt = v(t),    dv/dt = −a(v, t),    x(0) = 0,   v(0) = v₀
Solución Analítica (a = a₀ constante, t > tᵣ): v(t) = v₀ − a₀(t − tᵣ),    xdet = v₀·tᵣ + v₀² / (2a₀)
Escenario Parámetros Sintéticos Propósito de Verificación
NORMAL v₀ = 6.0 m/s, tᵣ = 0.8 s, a₀ = 1.2 m/s², h = 0.05 s Validar RK2/RK4 e integración numérica contra xdet = 19.80 m y tdet = 5.80 s.
ESTRÉS v₀ = 8.5 m/s, tᵣ = 1.5 s, a(v) = 0.75 + 0.01v², h = 0.4 s Evaluar aumento de distancia de frenado y error de truncamiento con paso grueso.
MAL CONDICIONADO a(v) = 0.5·√(v + 10⁻⁶) Derivada casi nula en v → 0; pérdida de convergencia cuadrática en Newton-Raphson.

Módulo 3: Oscilaciones Transversales por Viento

Sistema EDO: dx/dt = v,    dv/dt = (F(t) − c·v − k·x) / m,    Energía acumulada: E = ∫₀ᵀ x(t)² dt
Solución Analítica (F(t) = 0, subamortiguado ζ < 1): x(t) = e−ζω₀t [ C₁ cos(ωdt) + C₂ sin(ωdt) ]
Escenario Parámetros Sintéticos Propósito de Verificación
NORMAL m = 1200 kg, k = 4800 N/m, c = 480 N·s/m, F(t) = 0, h = 0.02 s Comparar RK2 y RK4 contra solución analítica subamortiguada.
ESTRÉS F(t) = 950·sin(2.0t) N, c = 96 N·s/m (ζ = 0.02), T = 60 s Analizar amplificación dinámica cerca de resonancia y acumulación de error en T largo.
MAL CONDICIONADO Sistema rígido (stiff): k = 4.8×10⁶ N/m con paso explícito h = 0.15 s Demostrar inestabilidad numérica de esquemas explícitos cuando h supera el límite de estabilidad.

Módulo 4: Reconstrucción de Señales de Sensores

Señal de Prueba: y(t) = sin(t) en [0, 2π] con nodos ocultados para medir error real de interpolación.
Métodos: Polinomio de Lagrange, Diferencias Divididas de Newton y Splines Cúbicos Naturales.
Escenario Configuración de Nodos Propósito de Verificación
NORMAL 9 nodos equiespaciados sin ruido; se ocultan 2 puntos internos. Comparar precisión entre interpolación polinómica global y splines cúbicos por tramos.
ESTRÉS 21 nodos con ruido gaussiano η ~ N(0, 0.05²) y brecha de 3 nodos. Evaluar propagación de ruido instrumental en las curvas reconstruidas.
MAL CONDICIONADO Fenómeno de Runge: 15 nodos equiespaciados en y(t) = 1 / (1 + 25t²). Evidenciar oscilaciones espúrias en extremos para polinomios de alto grado frente a splines.

Modelo Relacional SQL (Entregable Semana 1)

CREATE TABLE caso_estudio (id SERIAL PRIMARY KEY, codigo VARCHAR(20), nombre VARCHAR(100), modelo_version VARCHAR(20));
CREATE TABLE escenario (id SERIAL PRIMARY KEY, caso_id INT REFERENCES caso_estudio(id), tipo VARCHAR(20), parametros_json TEXT, fuente_datos VARCHAR(150));
CREATE TABLE simulacion (id SERIAL PRIMARY KEY, escenario_id INT REFERENCES escenario(id), fecha TIMESTAMP, equipo_autor VARCHAR(100), estado VARCHAR(20));
CREATE TABLE ejecucion_metodo (id SERIAL PRIMARY KEY, simulacion_id INT REFERENCES simulacion(id), metodo VARCHAR(50), tolerancia DOUBLE PRECISION, paso DOUBLE PRECISION, max_iter INT, convergio BOOLEAN, tiempo_ms DOUBLE PRECISION);
CREATE TABLE iteracion_resultado (id SERIAL PRIMARY KEY, ejecucion_id INT REFERENCES ejecucion_metodo(id), numero INT, aproximacion_json TEXT, residual DOUBLE PRECISION, error_abs DOUBLE PRECISION, error_rel DOUBLE PRECISION);
CREATE TABLE resultado_resumen (id SERIAL PRIMARY KEY, ejecucion_id INT REFERENCES ejecucion_metodo(id), referencia_json TEXT, valor_json TEXT, metrica_error_json TEXT, interpretacion TEXT);
